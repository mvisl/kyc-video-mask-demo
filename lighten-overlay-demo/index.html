Здесь не нужна маска. Модалка блюрит фон под собой, а видео внутри неё накладывается через Lighten.

По выбранному Figma-узлу `1972:30955`: сначала отдельный overlay затемняет весь экран примерно на 80%. Затем сама модалка рисуется полупрозрачной тёмной поверхностью и делает `Background blur`/`backdrop-filter` фона под собой. Уже внутри этой blurred-модалки лежит rocket video: `VIDEO fill`, `scaleMode: FILL`, `blendMode: LIGHTEN`, размер около `329 x 305`.

1. Screen dim Обычный прямоугольник поверх всего экрана: `rgba(17,17,17,.78)`. Он затемняет фон, но ничего не вырезает.
2. Modal blur Blur принадлежит самой модалке: `backdrop-filter: blur(20px)`. Он размывает только то, что находится под модалкой.
3. Video Lighten Rocket video находится уже внутри модалки и смешивается с её поверхностью через `mix-blend-mode: lighten`. 
<div class="screen-dim"></div>

<section class="signup-modal">
  <video
    class="signup-modal__rocket"
    src="./assets/rocket-video.mp4"
    autoplay
    muted
    loop
    playsinline
  ></video>
</section>

.screen-dim {
  position: absolute;
  inset: 0;
  background: rgb(17 17 17 / .78);
}

.signup-modal {
  /* This layer creates the blurred modal surface. */
  background: rgb(17 17 17 / .30);
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
}

.signup-modal__rocket {
  /* This media layer is inside the modal and uses Lighten. */
  width: 329px;
  height: 305px;
  object-fit: cover;
  mix-blend-mode: lighten; /* or screen */
  pointer-events: none;
}
Важно: не переносить Lighten на всю модалку. Модалка отвечает за blur фона под собой, а Lighten применяется только к video layer внутри неё.
